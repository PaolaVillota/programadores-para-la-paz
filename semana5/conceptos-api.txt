La ruta POST (reporte) recibe información enviada por el usuario mediante una solicitud POST.

El mensaje enviado se guarda y el servidor responde con un objeto JSON indicando que el reporte fue recibido.

Esta ruta podría servir en una aplicación comunitaria para recibir reportes ciudadanos, alertas de seguridad, daños en infraestructura, problemas ambientales o cualquier información enviada por los usuarios.
